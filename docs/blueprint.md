# **App Name**: RepoMDGen

## Core Features:

- Textual TUI: Textual-based user interface for interacting with the application in the terminal.
- AI Analysis: AI powered tool that analyzes the repository (existing or to be created) and proposes relevant sections for the README file. AI inference via ollama, lm studio, nexa ai, llama cpp, llamafile, mlx, etc using lightweight performant models such as gemma3.
- README Generation: Generates README content based on user input and the AI analysis of the repository. AI inference via ollama, lm studio, nexa ai, llama cpp, llamafile, mlx, etc using lightweight performant models such as gemma3.
- Content Editing: Allows users to edit and customize the generated README content.
- File Saving and Repo Creation: Saves the generated README file to the repository. For new repos, it will create the repo and initialize git.

## Style Guidelines:

- Primary color: Dark gray (#333) for the background.
- Secondary color: Light gray (#eee) for text and borders.
- Accent: Teal (#008080) for prompts and highlights.
- Monospace font for code snippets and readability.
- Clean and structured layout with clear separation of sections.
- Subtle animations for loading and feedback.

## Original User Request:
A TUI App that runs in the terminal to conversationally Generate Top of the Line README.md files for new Repos
